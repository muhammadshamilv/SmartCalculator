# Smart Calculator (Django)

A simple Django-based calculator web app supporting basic arithmetic operations.

## Features
- Add, Subtract, Multiply, Divide
- Input validation
- Clean UI with CSS & JavaScript

## Tech Stack
- Python
- Django
- HTML/CSS/JS

## Setup

```bash
git clone https://github.com/muhammadshamilv/SmartCalculator.git
cd SmartCalculator
python -m venv env
source env/bin/activate
pip install -r requirements.txt
python manage.py runserver
